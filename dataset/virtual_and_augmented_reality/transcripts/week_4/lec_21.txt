Scene graphs represent computer graphic scenes as a node-based graph.
So, essentially the entire scene is represented in the form of a tree with nodes and links between nodes, and we can selectively work with nodes to manipulate the scene and also create realistic effects and also allow interaction. So it is actually a very nice way of trying to represent the complexity of a scene as well as trying to work with the complexity of a scene. So it provides a way to manage the functionality of a complex graphics application. So scene graph-based representations generally aid in graphics applications.
Some of the features that typically scene graph-based representations provide have. So, they allow sorting objects according to visibility: which are visible with respect to viewer position and which should not be visible. It can allow removing objects out of camera field of view. So, this one is called visible surface detection, and this one is called clipping.
So, these operations that are typically part of any 3D graphics pipeline are easily managed and supported by this type of representation. Also, it can allow state management and higher level abstractions of functionalities. So, many things are possible if we go with scene graph-based representation.
