[39/227] We can sometimes have indirect manipulation where we are not directly manipulating using our physical hand.
[39/228] Instead, we are manipulating some other objects which in turn are manipulating the desired object.
[39/229] So, these other objects are mapped to the desired virtual object and by manipulating the other objects, we are essentially manipulating the desired objects.
[39/230] This is called indirect manipulation.
[39/231] It allows users to manipulate virtual objects without directly interacting with the virtual object.
[39/232] Instead, the user interacts with some other objects that are mapped to the virtual objects.
