[24/108] Usability, as we have started with, is a measure of how good a system is from the point of view of the user.
[24/109] So there are three crucial aspects, but along with that, there are three measures of usability.
[24/110] What are those measures?
[24/111] First is effectiveness, how effective the product is; efficiency, how efficient it is; and satisfaction, whether the user is satisfied.
[24/112] So, effectiveness essentially refers to whether the user is able to do whatever they want to do.
[24/113] Efficiency refers to how fast the user can do what they want to do, and satisfaction refers to how satisfied the user is when they are using the system.
[24/114] So, these are broadly the metrics to measure usability.
[24/115] Exact measurement techniques vary; it can be objective, it can be subjective, like we have seen before for measurement of presence or cybersickness, etc.

[24/118] And using that approach, whatever design comes up, that is called user-centered design.
[24/119] Now, this term was coined by Ben Shneiderman way back in 1986 in the context of graphical user interfaces that we are so familiar with.
[24/120] The objective was to design products that increase usability.
[24/121] Now when we are talking of user-centered design, it actually indicates involvement of the users either in an active manner or in a passive manner in the design lifecycle itself.
[24/122] So, remember that we talked about having a design or development lifecycle when we are building a software application, a usable software application.
[24/123] Now, when we are talking of user-centered design, what it refers to is involving users in that lifecycle itself either actively or in a passive manner.
[24/124] There are a few related terms which refer to a more or less similar idea.
