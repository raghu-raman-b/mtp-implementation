[62/23] How do we create scripts?
[62/24] So, unlike most other assets, scripts are usually created within Unity directly, based on using the interface provided by the IDE.
[62/25] So, we can go to Assets, then Create, then C# Script from the main menu to create a script.
[62/26] A new script will be created in whichever folder you have selected in the project panel.
[62/27] So, when you start a project, you select a folder and the script will be placed in that folder itself.
[62/28] Once the script is attached to the game object as per your design or development, the script will start working whenever you start executing the game.
