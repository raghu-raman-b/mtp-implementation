[62/114] There is a property called the transform property attached to every game object in a scene.
[62/115] This property is used to store and manipulate the position, rotation, and scale of an object.
[62/116] We can actually modify this property programmatically by writing a script, using which we can update the property.
[62/117] For example, here under the update function, we can have transform.translate, then parameter values for where to translate, then rotation for how to rotate, then local scale for how to scale it, and so on.
[62/118] So, this property we can manipulate through script to make the object behave. as per our wish, as per our interest.
