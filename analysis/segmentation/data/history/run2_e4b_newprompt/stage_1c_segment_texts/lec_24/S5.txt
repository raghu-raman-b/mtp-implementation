[24/107] Also, the ISO definition of usability reveals three measures.
[24/108] Usability, as we have started with, is a measure of how good a system is from the point of view of the user.
[24/109] So there are three crucial aspects, but along with that, there are three measures of usability.
[24/110] What are those measures?
[24/111] First is effectiveness, how effective the product is; efficiency, how efficient it is; and satisfaction, whether the user is satisfied.
[24/112] So, effectiveness essentially refers to whether the user is able to do whatever they want to do.
[24/113] Efficiency refers to how fast the user can do what they want to do, and satisfaction refers to how satisfied the user is when they are using the system.
[24/114] So, these are broadly the metrics to measure usability.
[24/115] Exact measurement techniques vary; it can be objective, it can be subjective, like we have seen before for measurement of presence or cybersickness, etc.
