Head-related transfer function

Head-related transfer function (HRTF) is a model that describes how a listener receives sound from a location in space. It depends on the size and shape of the head, ears, and ear canal, so each person’s is unique; an average listener’s is used, and a pair for both ears can synthesize binaural sound and support localization in XR.
