Glossary of terms

TermMeaning here
sentencea unit of the subtitles after stage 0a, ID lecture/index, with start and end times when they fall on a cue edge
segmentthe run of sentences in which the learner achieves one sub-goal; ID 30/S4
sub-goalwhat the learner can do after a segment, starting with a verb
objective, lecture goal, course goalthe three levels above the sub-goals (4b): a run of segments, a lecture, several lectures
factone complete point of subject knowledge a segment teaches, with the sentences that state it (its evidence)
segment concepta term named in one segment's facts (2c), with defined true when those facts say what it is
concepta course-wide term after the registry (3), ID C0042; defined or connecting
defined concepta concept the course explains; it has a written definition and is in the glossary (1,316)
connecting concepta concept the course only uses; it has a one-sentence role, stays on maps and cards, not in the glossary (1,806)
relationshipa directed triple subject – label – object stated by facts; labels are free text
lecture linkK → L when lecture L uses a concept K defines; direct, indirect or weak (4c)
hub concepta concept used by more than max(3, 25%) of the lectures; it weighs less in the lecture graph
knowledge layerthe folder knowledge/ stage 4d writes and checks
unitwhat one activity call covers: a segment (quiz, recap) or a lecture (the rest)
code check (hard / soft)a rule checked in code on a model answer; hard drops a still-failing item, soft keeps and flags it
judgea model call that checks finished items against named criteria
unresolvedevery attempt failed a check; the attempt with the fewest problems was kept
request hashthe key of the answer cache: engine, model path and the request body
round (QA)one model call in the tool loop; round 0 chooses tools with thinking on
coveredthe answer's own verdict, from its last line: the course answers the question (yes or partly) or not
F (Fable), O (Opus), U (user)the roles of PLAN.md: Fable plans, writes prompts and gold, reviews; Opus writes scripts, tests and reports; the user decides the design
gatethe end of a block: a report, a review by the block-reviewer agent, then “proceed” or “change”
MVPthe full-course run of 2026-11-13 (tag mvp-2026-11-13), with 2b, 3b and model-written 4a skipped
