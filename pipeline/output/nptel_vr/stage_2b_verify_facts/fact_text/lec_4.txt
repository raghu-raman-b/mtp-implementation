[4/S0/F0] The term virtual means, according to Webster's New Universal Dictionary, being in essence or effect but not in fact, that is, something that is there but cannot be attributed to any factual things.
[4/S0/F1] The term reality is defined in dictionary terms as the state or quality of being real, as something that exists independently of ideas concerning it, or as something that constitutes a real or actual thing as distinguished from something merely apparent.
[4/S0/F2] Virtual reality (VR) is, according to the Miriam Webster dictionary, an artificial environment experienced through sensory stimuli, in which sights and sounds play a primary role and are provided by a computer, possibly along with other sensory stimuli, and in which a person's actions partially determine what happens in the environment.
[4/S1/F0] A virtual reality (VR) system is defined by three characteristics: an artificial or synthetic environment, sensory experience through computer-generated stimuli, and user actions that partially determine what happens in the environment; a system with these aspects can be categorized as a virtual reality system and distinguished from other systems, which are not supposed to have these aspects.
[4/S1/F1] The artificial or synthetic environment of a virtual reality (VR) system is a computer-generated graphical representation of a real world or an imaginary or fantastic world, populated with artificial objects, and is not a real environment.
[4/S1/F2] An artificial environment in a virtual reality (VR) system can recreate a real world using real-world imagery or video, as in a virtual tour, but it still counts as a virtual reality system because it is a computer-generated scenario and changes are not happening in real time.
[4/S1/F3] The sensory experience characteristic of a virtual reality (VR) system means that the system provides computer-generated stimuli to the user's sensory organs, such as eyes and ears, so the user can immersively experience the artificial or synthetic environment, and this immersive experience is a hallmark of a virtual reality system.
[4/S1/F4] The user interaction characteristic of a virtual reality (VR) system means that the system must be interactive: the user can act on or interact with elements in the environment, and user actions or inputs partially determine what happens in the environment, producing dynamic changes in the virtual environment, just as people interact with objects in the real world.
[4/S2/F0] A system is a virtual reality (VR) system if it satisfies all three characteristics of a VR system—virtual environment, immersive experience through sensory organs, and interaction—and it is not a VR system if it does not satisfy at least one of them.
[4/S2/F1] A computer-aided design (CAD) system is not a virtual reality (VR) system because, although it supports a virtual environment and interaction, it does not support an immersive experience, since the user interacts with screen content through a mouse while still seeing the real world around the computer screen.
[4/S2/F2] A video conferencing system is not a virtual reality (VR) system because, although it is interactive, it is not a virtual environment or an immersive experience, since it presents a real-world environment in real time through a screen and the user remains in the real world, with the screen only aiding interaction.
[4/S2/F3] A three-dimensional (3D) movie experience is not a virtual reality (VR) system because, although it provides a virtual environment and a partly immersive experience, it is not interactive, as the viewer only watches and cannot change the displayed content.
