[52/S0/F0] A time-constrained virtual tour optimization approach seeks an optimal path that covers the maximum number of points of interest (POIs) while completing within the time threshold (TTH).
[52/S0/F1] The time threshold (TTH) for cybersickness (CS) is the maximum duration of a virtual reality (VR) tour, meaning the user's movement time, experience time, or VR exposure time should be kept within it, because crossing it may cause cybersickness.
[52/S0/F2] A virtual tour optimized to cover all vertices of a virtual world graph in minimum time may still induce cybersickness (CS) if its traversal time exceeds the threshold above which cybersickness occurs.
[52/S0/F3] There is no easy way to determine the time threshold (TTH); recommended thresholds may depend on content and movement speed, and a threshold can be obtained from an empirical study with a limited number of users or from pre-existing study results.
[52/S1/F0] When planning a tour to be completed within a given time threshold, visiting every node or vertex representing a point of interest is neither mandatory nor always possible.
[52/S1/F1] The importance of a node is assigned by an importance function that maps every node, vertex, or point of interest to a positive real number, with a larger number indicating higher importance.
[52/S1/F2] The importance of the nodes is needed to determine which nodes to cover within a given time threshold.
[52/S1/F3] The total importance of a path P containing nodes V1 through Vn is the sum of the individual importance f(Vi) for i = 1 to n, where n is the number of nodes in the path.
[52/S1/F4] The objective is to identify a path that takes time less than or equal to the time threshold and that has the maximum total importance among all such paths.
[52/S2/F0] In the virtual reality path optimization model, each node has two associated quantities: importance and waiting time.
[52/S2/F1] In the virtual reality path optimization formulation, the waiting time at a node, which is a point of interest, is the maximum time a user requires to inspect or interact with the object at that node, and it is represented by a waiting-time function W that maps each node v in V to a positive real number.
[52/S2/F2] For a path P with vertices v1 to vn, the total waiting time W(P) is the sum of the individual waiting times W(v_i) for i = 1 to n.
[52/S2/F3] The revised virtual reality path optimization problem maximizes the total importance F(P) of a path P subject to the constraint that the path's total completion time, T(P) + W(P), is less than or equal to the time threshold T_H.
[52/S3/F0] Vehicle routing problem with profit (VRPP) is a generalization of the vehicle routing problem (VRP), an operations research problem, in which not all nodes must be visited and the route maximizes profit within a time constraint, and in this formulation profit is the importance of the nodes.
[52/S3/F1] Existing vehicle routing problem with profit (VRPP) solvers can be used to find the optimal path that maximizes total importance of the nodes within the given time threshold.
[52/S3/F2] The optimized path must keep the user's exposure below a time threshold beyond which cybersickness may occur and, within that time, let the user visit as many of the most important points of interest (POIs) as possible.
[52/S4/F0] The input to the optimal-path algorithm for a virtual environment is the original graph G, which is a fully connected graph but not necessarily a complete graph, with vertex set V, edge set E, and importance f and waiting time w specified for each node.
[52/S4/F1] The desired output of the algorithm is the optimal path P that maximizes the importance value F, covers the maximum number of most important points of interest (POIs), and keeps the total exposure time, i.e. the traveling time plus the waiting time, less than the time threshold.
[52/S4/F2] The first stage of the algorithm is to compute the complete graph G dash by replacing every pair of vertices that is not directly connected with the shortest path between those vertices.
[52/S4/F3] The algorithm then replaces the edge weights in the complete graph, which are originally the Euclidean distances between node pairs, with travel times t computed using the natural walking model, producing the final graph G double dash, whose edges are weighted by travel duration to give a realistic experience.
[52/S4/F4] The final graph G double dash, together with the importance f and waiting time w of each node, is given as input to a virtual reality path planning (VRPP) solver, and the solver returns the optimal path P_opt.
[52/S4/F5] The optimal path returned by the solver is modified by replacing each hypothetical edge between vertices V_i and V_j with the shortest path between those vertices in the original graph, and the algorithm returns this modified optimal path.
