[55/S0/F0] The color values stored in the frame buffer are computed by the display processor, which is part of the display controller, in distinct stages.
[55/S0/F1] The graphics pipeline is the set of the distinct stages in which the color values stored in the frame buffer are computed.
[55/S1/F0] The three-dimensional (3D) graphics pipeline is the stage-wise process that computes the intensity values for each pixel, stores them in the frame buffer, and uses them to drive the display mechanism through the video controller.
[55/S1/F1] The three-dimensional (3D) graphics pipeline contains five stages: first object representation, second modeling transformation, third lighting, fourth the viewing pipeline, and fifth scan conversion.
[55/S1/F2] The first stage of the three-dimensional (3D) graphics pipeline, object representation, defines the objects that together form the rendered image in each object's own local coordinate system.
[55/S1/F3] The second stage of the three-dimensional (3D) graphics pipeline, modeling transformation, transforms objects from their local coordinate systems to the common world coordinate system to construct the scene.
[55/S1/F4] The third stage of the three-dimensional (3D) graphics pipeline, lighting or illumination, assigns color to the constructed scene in the world coordinate system, making the scene's three-dimensional nature more perceptible.
[55/S1/F5] The device coordinate system is equivalent to the screen, but it is not the same as the screen.
[55/S1/F6] The fourth stage of the three-dimensional (3D) graphics pipeline is a viewing pipeline that comprises viewing transformation, clipping, hidden surface removal, projection transformation, and window-to-viewport transformation.
[55/S1/F7] Within the viewing pipeline, viewing transformation maps the scene from the world coordinate system to the view coordinate system, clipping and hidden surface removal operate in the view coordinate system, projection transformation maps the three-dimensional (3D) view coordinate system to the two-dimensional (2D) view coordinate system, and window-to-viewport transformation maps the two-dimensional view coordinate system to the device coordinate system; together, these sub-stages transform a scene from the world coordinate system to the device coordinate system.
[55/S1/F8] The fifth stage of the three-dimensional (3D) graphics pipeline, scan conversion, transforms the continuous device coordinate system description, whose points can take real-number coordinates, into the discrete pixel-grid or screen coordinate system, where each pixel coordinate is an integer.
[55/S1/F9] Transforming an object definition to a pixel-level scene description in the three-dimensional (3D) graphics pipeline uses six coordinate systems: the local coordinate system, the world coordinate system, the three-dimensional (3D) view coordinate system, the two-dimensional (2D) view coordinate system, the device coordinate system, and the pixel-grid or screen coordinate system.
[55/S2/F0] The fundamental objective of three-dimensional (3D) object representation is to balance the requirement to represent objects of different shapes and sizes with their intricate details so that they render realistically in a synthesized environment, rather than as simplistic geometric approximations that lose realism, and the requirement to make the operations of the subsequent stages of the three-dimensional graphics pipeline efficient in space and time.
[55/S2/F1] In the three-dimensional (3D) graphics pipeline, the computation of pixel intensities depends on the object representation, and more complex representations lead to more complex calculations, so realistic rendering can suffer lags or require expensive hardware if the computation is not efficient.
[55/S2/F2] A single three-dimensional (3D) object representation technique is not sufficient because different object representation techniques are available, and the appropriate technique must be chosen for a particular problem.
[55/S2/F3] The broad categories of three-dimensional (3D) object representation techniques are point sample rendering, boundary representation, and space partitioning based representation, with boundary representation comprising mesh representation, parametric representation, and implicit representation, and space partitioning based representation comprising the octree method, binary space partitioning (BSP) method, and constructive solid geometry (CSG) method.
[55/S3/F0] The broad representation categories are point sample rendering, boundary representation, and space partitioning-based representation.
[55/S3/F1] Point sample rendering is the simplest broad representation category, in which the captured scene information is represented as a set of raw data points on the scene, with each point carrying that information as attributes.
[55/S3/F2] In point sample rendering, the scene information is captured from the real world in the form of points using input sensors such as three-dimensional (3D) range scanners, range finders, or computer vision techniques.
[55/S3/F3] In point sample rendering, the captured points are processed or mapped to pixels to generate a synthetic image, relying on real-world information rather than synthetically defining objects.
[55/S3/F4] Boundary representation is a broad representation category in which objects are represented by the surfaces that define the object's boundary, and those surfaces can be polygonal or curved.
[55/S3/F5] Mesh representation is a popular boundary representation technique in which object surfaces are assumed to be polygons, the connected polygons form a mesh that represents the whole object, and a vertex or edge list stores all vertices or edges and their connections, allowing the object to be reconstructed.
[55/S3/F6] Objects with non-polygonal surfaces can be represented using mesh representation by approximating the surfaces with polygonal meshes, typically triangles, although other simple convex polygons may also be used.
[55/S3/F7] In mesh representation, a greater number of polygons gives a better approximation of the surfaces but makes the vertex list more complex and harder to construct, so a trade-off must be maintained.
[55/S3/F8] Mesh representation is the most basic form of representation for any object in a rendered scene used in computer graphics, and all other representations are converted to a mesh representation at the end of the pipeline before the objects are rendered.
[55/S4/F0] Spline representation is a higher-level boundary representation for curved surfaces or curves that falls under parametric representation.
[55/S4/F1] Spline representation is typically preferred by developers or designers of scenes who want to create an artificial environment, and it is used to construct quality scenes for rendering and to represent complex surfaces with complex properties that cannot be represented by simple polygons or simple polynomial equations.
[55/S4/F2] In polynomial representation of a curve, a more complex curve is represented by a polynomial of higher degree, and computing points on a higher-degree polynomial becomes more time-consuming.
[55/S4/F3] In spline representation, a complete curve consists of several lower-degree polynomial pieces instead of a single higher-degree complex polynomial, and each piece is called a blending function or basis function so that simpler polynomials can compute points on the curve segment represented by that piece.
[55/S4/F4] Third-order polynomials are the most common form of polynomial used to construct spline curves.
[55/S4/F5] In spline representation, the polynomial pieces that make up the complete curve must join smoothly, and certain geometric and other properties need to be satisfied by each piece.
[55/S4/F6] In boundary representation, mesh is the most basic form, and higher-level boundary representations use implicit or parametric forms.
[55/S5/F0] Space partitioning representation is a broad category of object representation in which the three-dimensional (3D) space occupied by an object is divided into several disjoint, non-overlapping regions, so that any point inside the object lies in exactly one region and the object can be represented by representing the occupied regions.
[55/S5/F1] A space partitioning tree is a hierarchical, tree-like structure that represents the space occupied by an object and is used to create a space partitioning representation.
[55/S5/F2] Space partitioning representations include the octree method, binary space partitioning, and constructive solid geometric methods.
[55/S5/F3] Specialized sophisticated representation techniques are often required for application-specific or very complex photorealistic objects rather than the broader boundary or space partitioning categories.
[55/S5/F4] Fractal representation is a specialized representation method for self-repeating structures, such as a leaf whose individual parts repeat in the larger part.
[55/S5/F5] Particle system representation is a specialized representation method for objects such as a waterfall that relies on the simulation of physical properties.
[55/S5/F6] A skeletal model is a specialized representation method for complex characters such as a cat that captures the character's overall appearance and motion behavior, and such models are typically used in animation or computer animation to represent objects or complex characters.
[55/S6/F0] In an implementation of the three-dimensional (3D) graphics pipeline, all pipeline stages are present, the stages are more important than their sequence, and the order of the stages and sub-stages may differ from the stage-wise sequence used to show how the computations occur.
