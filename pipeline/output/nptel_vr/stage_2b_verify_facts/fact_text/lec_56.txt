[56/S0/F0] Rendering, the key component of any immersive experience in which the scene is rendered in front of the user's eyes on the display device, is covered by computer graphics, so some knowledge of computer graphics is needed to understand the complexities involved in rendering.
[56/S0/F1] Object representation in the three-dimensional (3D) graphics pipeline is called the first stage for simplicity, although there is no computation as such related to intensity calculation or determination of the pixel intensities.
[56/S1/F0] The three-dimensional (3D) graphics pipeline consists of five stages in order: object representation in the local coordinate system; modeling transformation, which transforms a local coordinate description to a world coordinate description; lighting, which takes place in the world coordinate reference frame; the viewing pipeline, which contains viewing transformation from the world coordinate system to a three-dimensional view coordinate system, clipping in the three-dimensional view coordinate system, hidden surface removal in the three-dimensional view coordinate system, projection transformation from the three-dimensional view coordinate system to a two-dimensional (2D) view coordinate system, and window-to-viewport transformation from the two-dimensional view coordinate system to the device coordinate system; and scan conversion, which transforms the device coordinate scene description to a screen coordinate or pixel grid description.
[56/S2/F0] Modeling transformation, also called geometric transformation and referred to as stage 2, applies operations to an object's local or object coordinate system description to place the object in a common scene or world coordinate system so that multiple objects can be assembled into a scene.
[56/S2/F1] An object's local or object coordinate system description is an individual definition of the object in which its position and dimension are defined in its own coordinate reference frame.
[56/S2/F2] The basic transformations in modeling transformation are translation, rotation by an angle clockwise or anticlockwise around an axis, scaling by increasing or reducing an object's size, and shearing by changing an object's shape; combinations of these four can create any transformation required to construct a scene.
[56/S3/F0] Each transformation is typically represented by a matrix in a homogeneous coordinate system, where one extra dimension is added, so a two-dimensional (2D) transformation can be represented by a 3 by 3 matrix and a three-dimensional (3D) transformation can be represented by a 4 by 4 matrix.
[56/S3/F1] Two-dimensional (2D) translation, rotation, scaling, and shearing in the homogeneous coordinate system can be represented by 3 by 3 matrices, using translation amounts Tx and Ty along the x and y directions, the rotation angle phi, scaling factors Sx and Sy along the x and y directions, and shearing factors Sx, Shx, and Shy along the x and y directions.
[56/S3/F2] A point (x, y) in an object's local coordinate system can be transformed to the world coordinate system by representing the point as the column vector P, multiplying it by the transformation matrix S to obtain the new point P dash, and thereby performing a matrix multiplication of points on the object's surface into new points that ideally should be in the world coordinate system.
[56/S4/F0] A composite transformation matrix is used when constructing a world coordinate scene requires multiple basic geometric or modeling transformations, such as translation, rotation, scaling, or shearing.
[56/S4/F1] In the worked example, transforming rectangle ABCD from its local coordinate system to the chimney-like shape A′, B′, C′, D′ in the world coordinate scene cannot be done with one basic transformation and requires two basic transformations, scaling and translation.
[56/S4/F2] In the worked example involving rectangle ABCD and the transformed chimney shape A′, B′, C′, D′, the scaling matrix has Sx (the scaling factor along the x direction) equal to 0.5 and Sy (the scaling factor along the y direction) equal to 1 because the object is halved in length while its height remains unchanged, and the translation matrix has Tx (translation along the x-axis) equal to 5 and Ty (translation along the y-axis) equal to 5 because vertex D at (0, 0) moves to D′ at (5, 5).
[56/S4/F3] A composite transformation matrix is formed by arranging the individual transformation matrices from right to left according to the order of application: the first transformation applied is placed rightmost, each subsequent transformation is placed to its left, and the matrices are multiplied.
[56/S4/F4] In the worked example involving rectangle ABCD and A′, B′, C′, D′, scaling is applied first and translation is applied second, so the translation matrix is placed to the left of the scaling matrix and the two matrices are multiplied to obtain the composite transformation matrix.
[56/S4/F5] To obtain transformed vertices in the world coordinate scene, each current vertex is multiplied by the transformation matrix; in the worked example involving rectangle ABCD and A′, B′, C′, D′, A′ = M A, B′ = M B, C′ = M C, and D′ = M D, where M is the composite transformation matrix.
[56/S4/F6] Matrix multiplication is not commutative, so the right-to-left sequence of transformations must be set correctly; an incorrect sequence may produce an incorrect transformed result.
[56/S5/F0] In the computer graphics pipeline, the third stage is color computation, which uses lighting or shading models to assign colors to objects in the scene; if a color is not assigned, depth cannot be perceived and the quality of experience is reduced, whereas properly assigning colors can give a more realistic perception.
[56/S5/F1] In computer graphics, lighting models and shading models are distinct, although they may physically represent more or less similar things, and they are differentiated by the computation involved: lighting models involve more computation than shading models, and shading models are used to reduce computation without compromising the quality of experience.
[56/S5/F2] Shading models are approximations of the color-assignment methods used by lighting models, and they rely on lighting models.
[56/S5/F3] Lighting models compute colors in terms of continuous intensity values, which are essentially real numbers, typically within the range 0 to 1 and typically normalized, and these values are mapped to computer-supported discrete values.
[56/S6/F0] A light source emits light that falls on a surface point directly, or in some cases after being reflected from surrounding surfaces, and the light incident at that point reflects to the viewer's eye; the intensity of the reflected light reaching the viewer's eye determines the color perceived.
[56/S6/F1] In computer graphics, a lighting model is used to simulate the reflection of incident light from a surface point to the viewer's eye, in order to compute the intensity of that reflected light, which is essentially the color of the surface point.
[56/S6/F2] In the simple lighting model, the light intensity reaching the viewer from a surface point is modeled as the sum of three intensities: ambient light intensity (I amb), diffuse reflection intensity of direct light (I diff), and specular reflection intensity of direct light (I spec).
[56/S6/F3] In the simple lighting model, the ambient light component is light that falls on a surface after being reflected from surrounding surfaces.
[56/S6/F4] In the simple lighting model, the diffuse light component is light that comes directly from a light source and is reflected in a diffuse manner from the surface.
[56/S6/F5] In the simple lighting model, the specular reflection component is light that comes from a light source and is reflected with a specular effect, producing a shiny bright spot.
[56/S7/F0] The intensity of light reflected from a surface and reaching the viewer's eye is a fraction of the incident light intensity, and this fraction is determined by the surface property known as the reflection coefficient or reflectivity.
[56/S7/F1] The simple lighting model defines three reflection coefficients: Ka for ambient light, Kd for diffuse reflection of direct light, and Ks for specular reflection of direct light.
[56/S7/F2] Each of the three reflection coefficients of the simple lighting model has a value from 0.0 to 1.0, where a value close to 0 represents a dull surface with no reflection because most of the light is absorbed, a value close to 1 represents a shiny, mirror-like surface where all light gets reflected, and varying the coefficients generates different effects between dull and shiny surfaces.
[56/S7/F3] The ambient component of the reflected light intensity is computed by multiplying the ambient light intensity falling on a surface point by the reflection coefficient for ambient light Ka.
[56/S7/F4] The diffuse reflection component is computed by multiplying the diffuse reflection coefficient for direct light Kd, the source light intensity Is, and the dot product of the surface normal vector N at the surface point from which light is reflected and the light source direction vector L, using that product only when N dot L is greater than 0 and otherwise setting it to 0, which means no diffuse reflection.
[56/S7/F5] The specular component is computed using an approximate model named after its inventor, Phong.
[56/S7/F6] The angle phi in the specular calculation is the angle between the viewer direction vector V and the ideal specular reflection direction vector r, which is the direction a mirror would reflect the light, and cos phi is the dot product V dot r.
[56/S7/F7] The specular component is computed as the specular reflection coefficient for direct light Ks times the source light intensity Is times the dot product of the viewer direction vector V and the ideal specular reflection direction vector r, raised to the power Ns, and it is 0 when V dot r is not greater than 0.
[56/S7/F8] The ideal specular reflection direction vector r is represented by r equal to twice the dot product of the light source direction vector L and the surface normal vector N, multiplied by the surface normal vector N, minus the light source direction vector L.
[56/S8/F0] In lighting, the intensity of light from a source typically diminishes with the distance from the source to a surface point, so an intensity attenuation factor over distance is needed.
[56/S8/F1] The radial intensity attenuation factor accounts for the diminishing of light intensity with distance and is typically computed as an inverse quadratic function of the distance d between the light source and the surface point, using coefficients a0, a1, and a2 that can be varied for a more realistic effect.
[56/S8/F2] Angular intensity attenuation is considered primarily for generating spotlight effects, in which elements inside the spotlight region are visible or brightly visible and elements outside the spotlight zone are darker.
[56/S8/F3] A commonly used angular intensity attenuation factor is 0 when the surface point is outside the angular limit theta, the range of the spotlight cone, and when the surface point is within that angular limit it varies as the cosine of phi raised to the power A1, where A1 is a positive angular attenuation exponent that can be varied to achieve different effects.
[56/S8/F4] In the simple lighting model modified for radial and angular intensity attenuation, the I_M intensity component is left unchanged, while the sum of the diffuse reflection component I_D and the specular reflection component I_SPEC is multiplied by the radial and angular attenuation factors; if those factors are 1, the model reduces to I_M + I_D + I_SPEC.
[56/S9/F0] In a colored light source model, emitted light intensity has three components corresponding to the primary colors red, green, and blue, rather than a single component, and the source intensity is the three-element vector Is = (Isr, Isg, Isb).
[56/S9/F1] In a colored light source model, the red, green, and blue components of the source intensity are computed individually, and their combination gives the perception of any color.
[56/S9/F2] In a colored light source model, the reflection coefficients named k, kd, and ks are specified as three-element vectors, each having the value one in the red, green, and blue components.
[56/S9/F3] For n light sources, the single-light-source lighting model is revised to I_P = I_ambient plus the summation from i = 1 to n of the contribution from each light source, with each contribution calculated separately and added together, and for colored light sources each contribution is computed separately for the red, green, and blue components.
[56/S10/F0] In intensity mapping, a lighting model computes a pixel intensity that can be any value in an infinite range between 0 and 1, whereas a display supports only a finite set of intensity values, such as 256 values per pixel on an 8-bit display.
[56/S10/F1] The determination of device-supported intensity values uses the number n of levels, the minimum device-supported intensity value I0 measured with a photometer, and the known maximum intensity value 1.
[56/S10/F2] The successive device-supported intensity values are represented by I1 = r I0, I2 = r^2 I0, I3 = r^3 I0, and so on up to In = r^n I0, where the factor r is computed using the relation In = r^n I0.
[56/S10/F3] The use of a multiplicative factor r in the successive device-supported intensity levels is based on the psychophysiological property that humans perceive relative changes between two intensity values rather than absolute changes in intensity values.
[56/S10/F4] A table stores the calculated device-supported intensity values and their assigned bit patterns, and a lighting-model pixel intensity is mapped to the nearest table intensity so that the corresponding bit pattern is stored in the frame buffer at the pixel location.
