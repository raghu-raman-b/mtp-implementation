[60/S1/F0] Unity is a popular and well-known programming environment for developers who wish to work with extended reality systems.
[60/S1/F1] The Unity platform comprises the Unity three-dimensional (3D) game engine and a developer's interface that a developer can use to implement ideas.
[60/S1/F2] The Unity platform is intended to provide implementation support for the computer graphics pipeline, including object definition, scene construction, lighting effects, view transformation, and scan conversion or rendering, so that a developer can focus on building the immersive experience rather than mastering and implementing the pipeline.
[60/S1/F3] Unity is a cross-platform game engine that Unity Technologies initially released in 2005.
[60/S1/F4] Unity supports both two-dimensional (2D) and three-dimensional (3D) games or interactive content, and it supports over 20 different platforms, including personal computer (PC), mobile, Android-based mobile, and Apple's iOS mobile platform.
[60/S2/F0] Unity Hub is a standalone application that is the primary way to install the Unity Editor and the Unity Game Engine; installing Unity Hub gives the Unity Editor interface and the Unity Game Engine and streamlines finding, downloading, and managing Unity projects and installations.
[60/S2/F1] The Unity Game Engine is a middleware and interface that allows developers to build extended reality experiences or extended reality systems and deploy them on a specific platform.
[60/S2/F2] The Unity Editor interface is essentially an integrated development environment (IDE) whose menu options provide developers the features required to build and deploy a system, and it allows developers to build and deploy realistic immersive environments without having to master and implement the computer graphics (CG) pipeline.
[60/S2/F3] The main advantage of Unity Hub is that it supports multiple versions of Unity and lets the developer manage multiple versions of Unity together in one place.
[60/S2/F4] Unity Hub installation is not mandatory; the Unity Editor and the Unity Game Engine can be installed separately, and in that case the developer can deal with only one version of Unity.
[60/S2/F5] Unity Hub can manually add versions of Unity that are already installed on a system, if any, to the Hub.
[60/S3/F0] In the Unity editor interface, the preference tab lets the developer select extended reality (XR) settings for three system types: virtual reality, which simulates a completely artificial environment around the user; mixed reality, which combines Unity's own environment with the user's real world environment and allows the environments to interact; and augmented reality, which provides layers of content over a digital view of the real world.
[60/S3/F1] The Unity editor interface includes the scene view, game view, hierarchy window, inspector window, toolbar, status bar, project window, and console window.
[60/S3/F2] The Unity scene view is the developer's interactive view of the scene being created, and it shows the scene while it is being built and lets the developer select, manipulate, and modify the game objects, which are the fundamental concepts in Unity, that together comprise the scene.
[60/S3/F3] The Unity game view is the final view used to preview a developed scene, and it renders the scene from the camera set by the developer to represent the final published or deployed application.
[60/S4/F0] A Unity asset is any item used in a Unity project to create an application, can represent visual or audio elements such as three-dimensional (3D) models or textures, and examples of Unity assets are scenes, animations, materials, scripts, and prefabs.
[60/S4/F1] A Unity asset can be imported from outside Unity as a file, such as a three-dimensional (3D) model, an audio file, or an image, or it can be created inside the Unity environment.
[60/S4/F2] A Unity scene is a specific type of Unity asset that contains all or part of a game or application, and a scene can comprise components, each of which can be a different asset.
[60/S4/F3] A Unity project can contain any number of Unity scenes, depending on how many levels or layers it has, and Unity provides a scene interface to create, edit, or modify a scene.
[60/S4/F4] A Unity game object is a fundamental object that represents characters, props, or a scenario and acts as a container for components that implement the object's functionality, so its properties are given by adding components to it.
[60/S4/F5] Built-in component types can be assigned to Unity game objects through the Unity editor interface, and custom components and game objects can be created using scripting application programming interfaces (APIs).
[60/S4/F6] Cube, sphere, capsule, cylinder, and plane are primitive object types that can be created directly within Unity as Unity game objects.
[60/S4/F7] A Unity prefab is a template created by configuring and storing a Unity game object, and it allows the user to make instances of that game object in a Unity scene.
