[39/S0/F0] In the design of immersive experiences, interaction is broadly categorized into three categories: object interaction, which is interacting with virtual objects in the immersive virtual world; navigation, which is moving from one point in the virtual world to another point with the corresponding change in viewpoint and mostly does not involve object interaction, although some navigation techniques may require it; and system control, which is a mostly regular type of interaction used to set up the system, initialize parameters, provide initial information, and set options or menus, and is unlike object manipulation, object interaction, and navigation.
[39/S1/F0] In any virtual experience, object interaction is broadly of two types: selection, which specifies one or more objects from a set of virtual objects in the virtual world, and manipulation, which interacts with a selected object to change its properties; the two types mostly have separate interaction techniques.
[39/S1/F1] For a given virtual experience, the kind of object selection technique that is suitable is determined by some of the most important parameters or variables that influence user performance while accomplishing the selection task, including the distance of the object to be selected from the current viewpoint or camera position, the direction of the object to be selected, the size of the object to be selected, the density of objects around the target object, and the number of targets to be selected, so that selection performance is maximized.
[39/S1/F2] Target occlusion can also be an important factor in selection performance: if a target is partly occluded by other surrounding objects, locating and selecting it is challenging and specialized techniques may be required, while fully occluded objects may also be selected, but the user must first be made aware of their presence, and specialized selection of fully occluded objects is a special case, with the majority of cases involving partially occluded or partially visible objects.
[39/S1/F3] Object selection techniques in a virtual world include selection with the hand, pointing-based selection, image plane selection, volume-based selection, and bimanual selection.
[39/S2/F0] A hand selection technique selects virtual objects in a virtual world with the user's hand by having the user directly reach out to virtually touch the object and trigger a grab; conventionally, selection with hand involves one hand, using a single finger or multiple fingers of one hand.
[39/S2/F1] Hand selection techniques for virtual objects include virtual hand, go-go, prism, and intent-driven selection.
[39/S2/F2] The virtual hand technique is the simplest and most intuitive hand selection technique, in which a visible virtual hand acts as an avatar of the user's physical hand and is tied to it through a one-to-one mapping of the physical hand's motion and orientation, typically implemented with three-dimensional (3D) tracked controllers, allowing natural hand movements.
[39/S2/F3] The virtual hand technique has a problem for selecting distant objects because moving the physical hand to reach them can require a long duration of physical hand movement, which can be tiring and annoying.
[39/S2/F4] The go-go technique is a virtual hand selection technique for distant objects that allows the user to interactively change the virtual arm length, the length of the virtual hand, uses one-to-one mapping when the target is close, and, as distance increases, maps smaller physical hand movements to larger and faster virtual hand movements, possibly exponentially, so that distant objects can be reached quickly.
[39/S2/F5] The go-go technique has a low-precision problem for selecting distant small objects because the virtual hand moves faster when the object is farther away, so a small physical hand movement can miss, bypass, or cross the target and is difficult to control.
[39/S2/F6] The prism technique is an improvement of the go-go technique that applies scaled-down motion to the virtual hand when the user's physical hand moves below a specified speed, and if the hand velocity is slower than a specified minimum velocity, the virtual hand remains still.
[39/S2/F7] For selecting distant objects, prism may provide a better solution than go-go because slowing or stopping the physical hand slows or stops the virtual hand, and the ability to stop the virtual hand when the physical hand stops is not present in go-go.
[39/S2/F8] Prism can result in a mismatch between the real and virtual hand positions because it does not use a one-to-one mapping, which may be counterintuitive.
[39/S2/F9] Intent-driven selection is a hand selection technique in which the user moves the virtual hand toward an object and positions virtual fingers, or uses the posture of virtual fingers, around the object to indicate the user's level of confidence in selecting that object.
[39/S2/F10] Intent-driven selection techniques typically use proximity spheres that encompass multiple objects at a larger distance and progressively reduce in size, depending on hand or finger postures, as the user moves closer to the intended object, refining the selection to a specific object.
[39/S2/F11] In hand selection techniques, go-go and prism are travel techniques, intent-driven selection is a grabbing technique, and intent-driven selection may be combined with a go-go or prism travel technique.
[39/S3/F0] Pointing-based selection is a selection technique in which the user operates a controller to extend a ray into the distance in the virtual world, sees the ray, and can select the first object intersected by the ray through a user-controlled trigger on the controller.
[39/S3/F1] Pointing for pointing-based selection can be done by hand pointing with a hand or handheld input device, by head pointing, in which a head-mounted display extends the ray from the head position and moves it with head movement without using the hand, or by eye-gaze pointing with an eye tracker.
[39/S3/F2] A virtual ray in pointing-based selection is a short line segment or an infinite line that can be attached to the virtual hand, head, or eye, with head position or eye gaze used when hand tracking is unavailable.
[39/S3/F3] Some pointing-based selection methods combine gaze pointing to estimate the target and hand pointing to trigger selection.
[39/S3/F4] Ray casting is the most basic way to extend a ray in pointing-based selection, in which the user points at objects with a virtual ray.
[39/S3/F5] In ray casting, selecting small distant objects is difficult and can require practice because the ray must be pointed precisely, and the difficulty increases when the small object is surrounded by other objects of similar, smaller, or larger size.
[39/S3/F6] Bend cast is an improvement over basic ray casting in which the system bends the ray toward the closest selectable object, detected by calculating the point-line distance from each selectable object, so the user need not point precisely, and a circular arc can provide visual feedback for the bending.
[39/S3/F7] Bend cast works best when only a few objects are near the ray's path, because with many nearby objects and similar distances the intended object may not be the closest, reintroducing the precision problem.
[39/S3/F8] Depth ray is an improvement over basic ray casting in which a user-controlled depth marker, positioned by moving the hand forward or backward, disambiguates multiple intersected objects and selects the object intersected by the pointing vector and closest to the marker.
[39/S4/F0] The third category of object selection techniques is image plane or volumetric selection.
[39/S4/F1] Image plane selection, also known as occlusion and framing, is a two-dimensional (2D) selection technique in which the user selects on a view plane that contains the object as viewed from a distance.
[39/S4/F2] In image plane selection, the user holds one or two hands or fingers between the eye and the desired object and provides a signal, such as a gesture or hand movement, to select the object when it lines up with the hand and the eye.
[39/S4/F3] The image plane selection techniques include the head crusher technique, the sticky finger technique, the lifting palm technique, and the framing hands technique, with framing hands being more common and the other techniques less common.
[39/S4/F4] In the head crusher technique, the user positions the thumb and forefinger so that they surround or enclose the desired object in the two-dimensional (2D) image plane.
[39/S4/F5] In the sticky finger technique, the object underneath the user's finger is selected.
[39/S4/F6] In the lifting palm technique, the user selects an object by flattening the outstretched hand and positioning the palm below the desired object as if trying to lift the object with the palm.
[39/S4/F7] In the framing hands technique, the user positions hands to form the two corners of a frame in the two-dimensional (2D) image surrounding an object, as typically seen while capturing movies or such visual media.
[39/S4/F8] Volumetric selection extends image plane selection by enabling the user to select a three-dimensional (3D) region in virtual space, with the objects within that region selected, where the region can be a box or cube, a sphere, or a cone.
[39/S4/F9] The cone casting flashlight technique is a volumetric selection technique that extends ray casting by casting a cone instead of a ray to a distance and selecting the objects within the cone.
[39/S4/F10] The cone casting flashlight technique can select multiple objects because the cone is volumetric, so selecting smaller or tightly grouped objects may be difficult.
[39/S4/F11] The sphere casting flashlight technique is a volumetric selection technique in which a sphere is cast onto the nearest intersected surface and the objects found within the sphere are selected.
[39/S4/F12] The two-handed box selection technique is a bimanual volumetric selection technique in which the user uses both hands to position, orient, and shape a box, usually a cube but possibly a rectangular parallelepiped, and progressively reduces it to select a specified region of three-dimensional (3D) space.
[39/S4/F13] Volumetric selection techniques are most useful for selecting small or well-defined isolated objects in a less complex virtual environment, and selecting smaller objects becomes problematic with any volumetric selection technique when the virtual environment is complex with many objects.
[39/S5/F0] Object manipulation is the modification of an object's properties such as position, orientation, scale, shape, color, texture, behavior, and others, and it typically follows selection of the object.
[39/S5/F1] Manipulation techniques include hand manipulation, indirect manipulation, bimanual manipulation, and integrated hybrid manipulation.
[39/S5/F2] Hand manipulation extends the virtual hand idea and uses a virtual hand to manipulate objects.
[39/S5/F3] Hand manipulation follows hand selection and is implemented using smart gloves, gesture-based manipulation, or controller-based interaction, and it is the most intuitive way of manipulating objects.
[39/S5/F4] Hand manipulation requires somewhat more computational power or specialized devices, which may be relatively costly.
[39/S6/F0] Indirect manipulation is a method sometimes used to manipulate virtual objects in which the user does not directly manipulate the virtual object using the physical hand, but instead manipulates other objects mapped to the virtual object, and those other objects in turn manipulate the virtual object.
[39/S6/F1] Three-dimensional (3D) widgets are a simple indirect manipulation technique in which controls are placed directly in the 3D scene with virtual objects, and manipulating a widget manipulates the associated virtual object.
[39/S6/F2] Each three-dimensional (3D) widget is typically responsible for only a small set of manipulation degrees of freedom, so a single widget may not be sufficient to manipulate all properties of a given object; instead, specified sets of degrees of freedom are manipulated using the individual widgets.
[39/S6/F3] Indirect proxies are an indirect manipulation technique that provides a more natural grasping method by letting the user manipulate a local proxy, such as a physical proxy prop linked to a neurological data set, so that moving the proxy moves the linked virtual object in the virtual world.
[39/S6/F4] World in miniature (WIM) is a type of indirect proxy that provides the user with a miniature handheld model of the virtual environment, which represents all objects in the virtual world, so manipulating an object in the miniature model manipulates the corresponding actual object in the virtual world.
[39/S6/F5] World in miniature (WIM) allows manipulation of virtual objects both within and outside the user's reach; for a distant object, the user does not need to select it, but can manipulate its representation in the miniature model, which then manipulates the distant object.
[39/S6/F6] Implementing world in miniature (WIM) for large and complex virtual environments is not very practical because creating the miniature model for such environments is very difficult.
[39/S7/F0] A bimanual manipulation technique manipulates objects with both hands, and its hand movement can be synchronous, in which both hands move together, or asynchronous, in which the hands do not need to move simultaneously.
[39/S7/F1] The spindle technique is a symmetric synchronous bimanual manipulation technique that uses two handheld controllers with six degrees of freedom, placed symmetrically on both sides of an imaginary axis and moved simultaneously, to define a virtual spindle.
[39/S7/F2] In the spindle technique, moving both hands in unison can move a virtual world object, and the technique can also be used to rotate the object simultaneously.
[39/S7/F3] The spindle technique is not easy to use because it requires synchronous hand movement while interacting in a virtual world, which is not necessarily easy for everybody and requires a lot of practice to use efficiently.
[39/S7/F4] Spindle plus wheel is an asymmetric but synchronous technique and an extension of the spindle technique, in which both hands need to be moved together but need not be symmetrically placed around the sides of an imaginary axis.
[39/S8/F0] Integrated hybrid manipulation techniques are techniques that switch automatically from selection to manipulation after selection, without any explicit signal from the user, and switch back to selection mode after manipulation.
[39/S8/F1] Hand-Centered Object Manipulation Extending Ray Casting (HOMER) is an integrated hybrid manipulation technique that mixes ray casting, a pointing-based selection method, with hand manipulation, so selection and manipulation are integrated and the user does not need to perform them separately.
[39/S8/F2] In Hand-Centered Object Manipulation Extending Ray Casting (HOMER), the user selects an object using a ray casting technique, and when the ray intersects the desired object, the user's virtual hand moves automatically to the object and attaches to it, rather than the ray being attached to the object.
[39/S8/F3] In Hand-Centered Object Manipulation Extending Ray Casting (HOMER), after the user's virtual hand attaches to the object, the technique switches to manipulation mode, allowing the user to change the object's position and orientation through hand manipulation.
[39/S8/F4] In Hand-Centered Object Manipulation Extending Ray Casting (HOMER), manipulation ends when the user indicates to the system that the manipulation job is done through a trigger or a specific hand gesture, after which the virtual hand returns to its original position.
[39/S9/F0] Augmented reality systems allow regular interaction techniques to be used to interact with the virtual augmentation of the real world because the user's senses are not blocked.
[39/S9/F1] Immersive environments block the user's senses and cut the user off from the real world in the ideal case, so improved interaction techniques are needed to provide a better immersive experience.
[39/S9/F2] Object selection and object manipulation are two interaction techniques, typically used in immersive environments, that are related to virtual objects.
[39/S9/F3] Navigation techniques are interaction techniques for moving from one point to another in a virtual world.
[39/S9/F4] System control interaction is a third category of interaction that primarily relies on regular interaction techniques that are familiar when dealing with any computer system.
