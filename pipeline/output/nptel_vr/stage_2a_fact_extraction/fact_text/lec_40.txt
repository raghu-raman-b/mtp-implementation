[40/S0/F0] The goal of navigation in a virtual world is to move the user from one point to another, which means a change of the user's field of view or viewpoint.
[40/S0/F1] The movement involved in navigation in a virtual world has two parts: the travel part and the wayfinding part.
[40/S1/F0] The travel part of navigation, also called locomotion, is the motor component of navigation and refers to the actual movement between two locations.
[40/S1/F1] Locomotion techniques, alternatively travel techniques, are techniques employed to let a user travel in a virtual world from one place to another and to perceive that travel has taken place.
[40/S1/F2] Travel in navigation can be done by exploration, search, or maneuvering: exploration has no explicit goal or target point and the user moves around to see, learn, or explore; search is moving to a specified target location; and maneuvering comprises short, precise movements that change the viewpoint or break a path into small segments to reach a destination.
[40/S1/F3] Travel in navigation can be accomplished using four broad types of locomotion techniques: walking-based locomotion, steering-based locomotion, selection-based locomotion, and manipulation-based locomotion.
[40/S1/F4] In the four broad locomotion technique types, object manipulation may not be involved in walking-based, steering-based, or selection-based locomotion; manipulation-based locomotion involves navigating by manipulating certain things, and navigation mostly involves no object manipulation while manipulation is not entirely avoided when implementing travel techniques in an immersive setting.
[40/S2/F0] Walking-based locomotion is a technique for traveling in a virtual environment in which physical walking or movement in the physical world is mapped to corresponding movement in the virtual environment.
[40/S2/F1] Walking-based locomotion is broadly divided into three categories: full gait techniques, partial gait techniques, and gait negation techniques.
[40/S2/F2] In full gait techniques, the user actually walks in the real world and that walk is translated to virtual movement in a virtual environment, which is the most natural way to travel.
[40/S2/F3] In full gait techniques, completely free walking is not practical or possible for virtual navigation, so walking is restricted within a specified limit in the physical space and translated to any amount of movement in a potentially infinite virtual space, creating a mismatch between physical and virtual movement.
[40/S2/F4] In a partial gait technique, the user walks in place, so the user does not change position and is not actually moving forward, backward, left, or right.
[40/S2/F5] Partial gait techniques require specialized devices in addition to other immersive hardware to provide input, may involve active walking interfaces such as pressure mats, pressure sensors, or interfaces with pressure sensors, and map the user's pattern of walking in a single place to different types of walking in the virtual space.
[40/S2/F6] Gait negation techniques require a specialized setup that cancels the user's lateral movements and keeps the user's physical position fixed, because natural walking involves lateral movement that may be difficult to map to a focused virtual movement, and the setup detects and eliminates the lateral movement before the movement is mapped to virtual navigation, making it easier for the system to understand the user's intention.
[40/S2/F7] Some examples of specialized setups used in gait negation techniques are a linear treadmill, motorized floor tiles, a human-sized hamster ball, and a friction-free platform.
[40/S3/F0] Steering-based navigation is a navigation category in which direction and speed are continuously controlled while the user moves from one point to another, and continuous control of direction and speed essentially indicates that a system has implemented steering-based navigation.
[40/S3/F1] Steering-based navigation has two types: spatial steering-based navigation, which is controlled using the user's body parts, and physical steering-based navigation, which is controlled using vehicular props or additional hardware.
[40/S3/F2] Spatial steering-based navigation can be gaze-directed, where looking at a target location moves the user continuously in the direction of looking; hand-directed, where hand gestures determine the direction of travel; or body-leaning directed, where leaning the body toward a movement direction is mapped to corresponding travel.
[40/S3/F3] Physical steering-based navigation involves physical setups or separate hardware, such as bike locomotion platforms and virtual reality (VR) simulators for aircraft, merchant ships, cars, boats and spaceships, in which physically moving the steering controls travel in the virtual world.
[40/S4/F0] Selection-based locomotion is a category of locomotion technique in which the user selects where to go rather than continuously specifying how to move there by steering or looking.
[40/S4/F1] Selection-based locomotion has two types: target selection-based locomotion and route planning-based locomotion.
[40/S4/F2] In target selection-based locomotion, the user selects a destination or target, and the virtual viewpoint changes so that the user feels moved to the target.
[40/S4/F3] Target selection-based locomotion techniques include teleportation, which instantly changes the virtual viewpoint from the current location to the target location, map dragging, in which the user fixes a location to move there instantly, and the jumper technique in cave-type systems.
[40/S4/F4] Route planning-based locomotion is a selection-based locomotion technique in which the user selects a route to the target rather than only the endpoint; there may be multiple routes, and while moving through the selected route, different viewpoint changes make the user feel movement along a path, providing more granular control over travel and slightly more natural movement than target-based teleportation.
[40/S4/F5] Manipulation-based locomotion is a category of locomotion technique in which the user's position, orientation, or scale is manipulated using gestures that control either the virtual viewpoint or the virtual world.
[40/S4/F6] Manipulation-based locomotion can be implemented using a combination of the go-go technique, homer technique, and world in miniature metaphor.
[40/S4/F7] In a world in miniature metaphor, moving or manipulating certain objects causes a corresponding change in the virtual viewpoint, as if the user moves from one place to another.
[40/S5/F0] Navigation has two components: locomotion or travel, which is the motor component, and wayfinding.
[40/S5/F1] Wayfinding refers to location awareness, ascertaining a path through the environment to a desired destination, and transferring spatial knowledge to the real world.
[40/S5/F2] Wayfinding is essentially a mental model, and the goal of wayfinding is to build a mental model or cognitive map of the surroundings and overall environment so that it is easier to locate oneself and identify a suitable path.
[40/S5/F3] The objective of environment design is to make it easier for the user to build a mental map; if the design does not support creation of this mental map, many problems may occur and the overall user experience deteriorates.
[40/S5/F4] The spatial knowledge in a wayfinding mental model consists of landmark knowledge of the surroundings and other places, procedural knowledge of the sequence of actions required to follow a path, and topological or map-like knowledge of the overall environment, together forming the essential knowledge base of the mental model.
[40/S5/F5] A mental model can be created by aiding the user to get, understand, or infer knowledge through the traditional methods of systematic study of a map of a place, exploration of real space, exploration of a copy of the real space or a model of the real space, or any combination of these methods.
[40/S5/F6] For a good immersive user experience in a complex virtual environment with many objects and different ways to reach targets, wayfinding support is essential; locomotion or travel support alone is not sufficient, and regardless of how many or how sophisticated the travel techniques are, without suitable wayfinding support the user cannot use them efficiently or effectively.
[40/S5/F7] Landmark support for wayfinding uses obvious distinct non-mobile objects positioned in a given place, and a good landmark should be clearly visible from several different locations or viewpoints.
[40/S5/F8] Map support for wayfinding can provide maps of the space or place, such as a copy of the virtual world map, where the term world means the virtual world rather than the real world, or a world in miniature display that can show the entire virtual world with objects at different points, the current position of the user, and different routes to different points.
[40/S5/F9] Path following support for wayfinding can denote multiple paths through a single space by colors, so the user knows that there are different paths to reach a destination.
[40/S5/F10] Breadcrumb support for wayfinding leaves a trail of markers along the path followed by predecessors, so users can recognize that a path has already been explored, avoid getting lost, and choose another path or destination to save time.
[40/S5/F11] A compass or another direction indicator can support wayfinding by specifying directions in two-dimensional or three-dimensional space, and a compass can be designed and placed in the environment.
[40/S6/F0] Interaction for system control is an interaction technique whose goal is to issue commands that change system state or mode, such as launching an application, changing system settings, or opening a file, and these commands are most of the regular operations associated with using any software.
[40/S6/F1] Interactive methods for system control include physical controllers such as buttons and switches; graphical menus, adapted two-dimensional (2D) menus suitable for three-dimensional (3D) massive environments, one degree of freedom menus, and three-dimensional widgets; voice commands; gesture commands such as mimic gestures, symbolic gestures, sweeping gestures, sign language, speech-corrected hand gestures, and whole-body interactions; tools such as physical tools, virtual tools, and tangible interfaces; and multimodal interaction techniques that combine multiple techniques, for example voice with gestures or other interactions.
