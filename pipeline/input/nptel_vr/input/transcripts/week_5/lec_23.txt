This brings us to the user-centric approach, which is generally recommended for building interactive systems. This is the process to design computer systems in which the users' needs and expectations are taken care of by considering their characteristics. So essentially, in a user-centric approach, we start by understanding the user characteristics, what they need, what they expect, and based on that, we come up with the design of the system. Now this leads to several things such as designing the interface elements, the elements with which the user interacts that are acceptable to the users.
Design the layouts, that is, the way the elements are organized on the screen or on the interface, that meet the user's expectations. Help the user perceive the system state, what exactly is happening from the point of view of the user, not from the point of view of technical details, and also design interactions that fulfill the needs of the users by taking them to the desired system states. So, essentially, what the user wants is to get some work done; that means from one state to another they have to transition until they reach some goal state. So, we need to have properly designed interactions that allow the user to easily transition to the goal state.
